\begin{beginnerstatement}[Kurz erklärt: Technische Verantwortungsbereiche]

Das Frontend ist der sichtbare Teil einer Anwendung, den Menschen bedienen.
Das Backend arbeitet im Hintergrund und verarbeitet Anfragen oder stellt Daten
bereit. Eine Desktop-Schicht bindet die Anwendung an ein Betriebssystem und
ermöglicht dort zusätzliche Funktionen. Persistenz sorgt dafür, dass Daten
über das Beenden eines Programms hinaus erhalten bleiben. Deployment bezeichnet
das Bereitstellen und Starten der Anwendung in ihrer Zielumgebung. Das Template
soll diese Bereiche klar trennen; an dieser Stelle sind das zunächst
Anforderungen und noch keine bestätigten Prüfergebnisse.

\end{beginnerstatement}
