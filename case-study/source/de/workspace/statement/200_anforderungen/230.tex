\begin{beginnerstatement}[Kurz erklärt: Plattformen und API]

Web, Cloud und Desktop bezeichnen hier die bereits eingeführten
Browser-, servergestützten und lokal installierten Anwendungsformen. Full Stack
bezeichnet eine Lösung, die sowohl das sichtbare Frontend als auch ein Backend
umfasst. Eine API ist eine festgelegte
Schnittstelle, über die Programme Anfragen und Daten austauschen. Die Profile
des Templates kombinieren diese Bereiche unterschiedlich; nicht jede Variante
benötigt deshalb ein Backend oder eine Datenbank.

\end{beginnerstatement}
