\begin{beginnerstatement}[Kurz erklärt: Technische Basis einer Business-Anwendung]

Eine Business-Anwendung unterstützt Arbeitsabläufe in einem Unternehmen, zum
Beispiel die Bearbeitung und gemeinsame Nutzung von Daten.

Die Fachlogik umfasst die Regeln und Abläufe des konkreten Geschäftsbereichs.

Eine technische Ausgangsbasis stellt allgemeine Bausteine wie Oberfläche,
Backend oder Deploymentstruktur bereit, auf denen ein Produkt aufgebaut wird.

Das Template liefert eine solche Basis, aber weder die Fachlogik noch die
fertige Geschäftsanwendung.

\end{beginnerstatement}
