\begin{beginnerstatement}[Kurz erklärt: web-cloud]

\texttt{web-cloud} ist eine Browseranwendung mit einem getrennten
FastAPI-Backend. Das Profil bringt außerdem eine anbieterneutrale Grundlage
für das Deployment mit. Eine PostgreSQL-Datenbank kommt nur über die separat
gewählte Capability hinzu.

\end{beginnerstatement}
