\begin{beginnerstatement}[Kurz erklärt: desktop-cloud]

\texttt{desktop-cloud} ist eine Tauri-Desktopanwendung mit einem zentralen
FastAPI-Backend. Der Desktop-Client erreicht dieses Backend über eine
öffentliche URL. PostgreSQL ist möglich, bleibt aber eine optionale
Erweiterung.

\end{beginnerstatement}
