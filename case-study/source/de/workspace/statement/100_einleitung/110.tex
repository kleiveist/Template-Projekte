\begin{beginnerstatement}[Kurz erklärt: Arten von Softwareprojekten]

Ein Softwareprojekt umfasst die geplante Entwicklung oder Anpassung eines
Computerprogramms. Eine Web-Anwendung wird meist im Browser geöffnet. Eine
Cloud-Anwendung nutzt Dienste, die auf Servern bereitgestellt und über ein
Netzwerk erreicht werden. Eine Desktop-Anwendung wird dagegen auf einem
Computer ausgeführt und kann dessen Betriebssystem direkt einbeziehen. Das
untersuchte Template soll für diese verschiedenen Projektarten eine gemeinsame
technische Ausgangsbasis liefern.

\end{beginnerstatement}
