\subsection{Desktop-cloud Profile}
\label{subsec:profil-desktop-cloud}

\texttt{desktop-cloud} connects the Tauri frontend to the separate FastAPI
backend through a public URL and adds deployment files. PostgreSQL is
compatible but remains optional
\parencite{kleiveist2026profiles,kleiveist2026deployment}.

The technical base features correspond to \texttt{full-platform}; the profile
ID, however, identifies the desktop client as the intended product channel.
The distinction is semantic: it does not introduce an additional technical
component.
