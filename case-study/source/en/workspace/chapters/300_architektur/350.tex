\subsection{Shared Contracts and Interfaces}
\label{subsec:shared-contracts-schnittstellen}

\texttt{shared/} is included in every generated project. It contains static
assets, a JSON Schema conforming to Draft~2020-12, and valid and invalid test
examples. The contents are serializable and framework-neutral, but define
neither a product API nor executable framework code
\parencite{kleiveist2026architecture,kleiveist2026template}.

However, the runtime does not use the schema automatically: neither the
frontend nor the backend imports it. The health contract is likewise mirrored
manually as a TypeScript interface and a FastAPI response. Without code
generation or synchronization, contract changes must be propagated on both
sides and in consumer tests. The documented target role of shared contracts is
therefore not yet fully implemented.
