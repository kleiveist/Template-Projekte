\begin{beginnerstatement}[In simple terms: full-platform]

\texttt{full-platform} offers the browser and desktop as two ways to access
the same technical base of frontend and backend. Both use the same FastAPI
backend. Despite the name, a database is not included automatically.
\texttt{postgres} is the selectable server-side database extension; other
storage forms remain product decisions.

\end{beginnerstatement}
