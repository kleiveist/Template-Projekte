\begin{beginnerstatement}[In simple terms: The smallest suitable profile]

The smallest suitable profile contains only the technical components that a
project actually needs.

The technical selection is based first on whether a browser, desktop
application, and backend are required.

PostgreSQL is then assessed separately and added only to a suitable backend
profile.

This approach avoids unnecessary components and the additional complexity
they create.

If a profile does not meet central requirements, a different architecture or
clearly limited partial use should be examined instead of selecting the
largest profile.

\end{beginnerstatement}
