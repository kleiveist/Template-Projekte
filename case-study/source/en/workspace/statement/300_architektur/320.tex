\begin{beginnerstatement}[In simple terms: Vite and TypeScript]

The frontend is the visible, interactive side of the application. JavaScript is
a language used for such applications; TypeScript extends JavaScript with type
annotations that reveal certain errors during development. Vite is the tool
that starts a development server and later produces the build. The development
server makes the application available locally while it is being programmed,
whereas the build creates the distributable files in
\path{frontend/dist}. Vitest runs automated tests for frontend code. The HTTP
client sends requests to a backend using a URL, which is its address on the
network. In the template, this access is enabled only for profiles with a
backend.

\end{beginnerstatement}
