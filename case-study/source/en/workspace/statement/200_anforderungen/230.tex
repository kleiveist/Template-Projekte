\begin{beginnerstatement}[In simple terms: Platforms and API]

Here, web, cloud, and desktop refer to the browser-based, server-supported, and
locally installed forms of application introduced above. Full stack describes a
solution that comprises both the visible frontend and a backend. An API is a
defined interface through which programs exchange requests and data. The
template's profiles combine these areas in different ways; consequently, not
every variant requires a backend or a database.

\end{beginnerstatement}
