\begin{beginnerstatement}[In simple terms: A baseline rather than a finished product]

The scope defines what an investigation or solution includes and what lies
outside its target area. Product-specific functions are those required only for
a particular use case or customer. The baseline provides shared technical
foundations but is not yet a finished product. Domain rules, concrete data
models, and appropriate access rights must therefore be added to each product
project.

\end{beginnerstatement}
